# KAFD00330 — Procurement Master Tracker

Live, self-contained procurement dashboard for contract KAFD00330
(RO Plant and Collection Ground Water System).

**Open the site:** the `index.html` at the repository's GitHub Pages URL.

- Single self-contained HTML (no build, no server).
- Delivery, 2-Week Look Ahead, FAT Register, Spare Parts, KPI Dashboard.
- To update the published data: re-export `index.html` from the report
  (Tools → Export shareable copy) and re-upload it to this repo.
